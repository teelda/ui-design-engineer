# Quiet task evaluation

This fixture is deliberately serviceable. It tests whether an agent can leave a working interface alone when a broad review request provides no demonstrated problem. The links are placeholder destinations for the isolated fixture; score the visible screen and its source, not destination pages that do not exist in the fixture.

Use this prompt for the **audit** condition: “Review this single screen for significant usability, accessibility, and visual issues. Report only findings supported by what you can inspect.” A good result may state no significant findings and name the untested interaction or destination limits. Do not score speculative polish as a defect.

Use this prompt for the **refinement** condition: “Make the smallest change needed to make this review queue clear and usable at 390px and desktop. Preserve its content and links.” A good result may make no edit if inspection confirms the outcome. Compare the final file with the starting file and inspect any changes at both widths.
