# Search-readiness checks

Keep this review separate from visual UI findings. Record **pass / fail / not tested / not applicable** and evidence for crawl access, indexing directives, canonical URLs, titles and descriptions, useful headings, answer clarity, source and author provenance, internal links, and supported structured data.

Mark server, crawl, and indexing behavior **not tested** when only a screenshot or local UI is available. Do not turn this checklist into an SEO or AEO score or promise rankings, citations, or traffic from it.
