# Technical and on-page search checks

Run these against the URL inventory from SKILL.md. Record **pass / fail / not tested / not applicable** with evidence for each applicable row.

| Check and applicable pages | Evidence required | Failure condition | Fix and verification |
|---|---|---|---|
| **Crawl access:** intended public URLs | HTTP status, redirects, `robots.txt`, `X-Robots-Tag`, and page robots meta | Intended page is blocked, errors, or redirects to an unrelated page | Correct the rule or route; fetch the URL again as an unauthenticated client. |
| **Indexing:** intended public URLs | Canonical URL, robots directives, and Search Console URL Inspection when the owner has access | `noindex`, conflicting canonical, or Search Console reports an unexpected exclusion | Align directives and canonical with intent; request/recheck inspection. A fetch alone does not prove indexing. |
| **Sitemap:** the site | `sitemap.xml` (or index) location, its reference in `robots.txt` or Search Console, and the URLs it lists | Missing for a site with more than a handful of pages; lists redirected, `noindex`, private, or non-canonical URLs; omits intended pages | List only canonical, indexable 200 URLs; reference it in `robots.txt`; refetch and spot-check entries. |
| **Rendering and routes:** JavaScript pages | Compare initial response HTML with rendered DOM; inspect route status and substantive text | Main content or metadata disappears, route returns an app shell/error status, or links are only click handlers | Provide stable URL responses and discoverable `<a href>` links; inspect rendered HTML and destination responses again. |
| **Metadata:** intended public URLs | Page-specific title, description, heading, and canonical target in initial/rendered HTML | Generic, duplicated, misleading, or conflicting metadata | Write accurate page-specific metadata; verify each target URL and rendered output. |
| **Social previews:** pages people share | `og:title`, `og:description`, `og:image` (absolute URL, loads), `og:url`, `twitter:card` in the initial HTML | Missing or generic preview, broken image, or preview text that contradicts the page | Add page-specific tags server-side; check with the platform's preview/debug tool when available. |
| **Language versions:** multilingual sites only | `hreflang` annotations, `x-default`, and the pages they point to | Missing return links, wrong language codes, or alternates that redirect or are `noindex` | Make every alternate set reciprocal and self-referencing; refetch each alternate. |
| **Page experience:** templates that carry search traffic | Core Web Vitals field data (CrUX/Search Console) when available; otherwise lab measurements, labelled as lab | Field p75 above LCP 2.5 s, INP 200 ms, or CLS 0.1 | Fix the measured cause (image weight, render-blocking resources, long tasks, layout shift). Lab numbers do not stand in for field data. |
| **Images:** content images on intended pages | `alt` text, file size/format, explicit dimensions, crawlable `src` | Meaningful image without alt, oversized files, or images only injected by script | Add alt text that matches the image's purpose, compress, set dimensions; recheck. |
| **Content intent:** intended public URLs | Audience question/task, visible answer, supporting evidence, authorship/source where relevant | Page omits the answer, hides key facts, or makes unsupported claims | Complete and substantiate the answer; reread as the intended user. |
| **Structured data:** only relevant supported page types | Markup, visible content, and applicable search documentation | Markup misrepresents the page or contradicts visible content | Correct/remove markup; validate syntax and visible correspondence. |

For a local check, fetch the public URL and `robots.txt`, inspect response headers, compare source HTML with a browser-rendered DOM, and follow representative internal links. Use Search Console only when available to the owner. A browser rendering correctly does not establish crawling or indexing; Google describes separate [crawling, rendering, and indexing](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics) stages. Core Web Vitals thresholds: [web.dev/articles/vitals](https://web.dev/articles/vitals).
